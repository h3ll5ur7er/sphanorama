    Phase 0 walking skeleton. Sensors and camera run in the page; the managers run in the core behind a generated facade, and the reticle is the plan the core built. The field of view is assumed — browsers do not report it, so the plan uses 66° horizontal scaled by your camera’s real aspect ratio until Phase 2 estimates the true focal length from captured frames. A burst captures real pixels into the frame store, and a captured cell’s frames are spilled out of the heap so a whole sphere fits. The strip below shows what the core knows about each candidate; the frames themselves are not drawn yet, because reading pixels back out of the store has no path across the worker. Markers are placed in the video’s own box and mapped through the crop object-fit: cover applies (ADR 0028).
